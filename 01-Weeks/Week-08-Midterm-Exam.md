## แนวทางทบทวน (Study Guide)

### ต้องจำได้ขึ้นใจ
- ระบบย่อย 4 ส่วนของ DSS พร้อมหน้าที่และเป้าหมายเชิงกลยุทธ์ → [[DSS-Architecture-Subsystems]]
- 4 ระยะของ Simon และเทคโนโลยีที่สนับสนุนแต่ละระยะ → [[Simon-Decision-Phases]]
- 6 ระยะของ CRISP-DM → [[CRISP-DM]]
- การดำเนินการ OLAP ทั้ง 5 แบบ → [[OLAP]]
- สูตร Support / Confidence / Lift และ Precision / Recall / F1

### ต้องคำนวณได้
- ออกแบบ Star Schema จากความต้องการทางธุรกิจ (ระบุ fact, dimensions, granularity)
- ผลลัพธ์ของ roll-up / drill-down / dice จากตารางลูกบาศก์ที่กำหนดให้
- Information Gain / Gini สำหรับการเลือกโหนดแตกกิ่งของ Decision Tree
- เมตริกจาก Confusion Matrix
- Support / Confidence / Lift จากตารางธุรกรรม
- การวนรอบของ K-Means 1–2 รอบ

### ต้องวิเคราะห์และอธิบายได้
- จำแนกโครงสร้างปัญหาและอธิบายว่า DSS ช่วยตรงไหน → [[Problem-Structuredness]]
- เปรียบเทียบ OLAP กับ Data Mining
- เปรียบเทียบ OLTP กับ Data Warehouse
- วิจารณ์และปรับปรุงการออกแบบ dashboard → [[Dashboard-Design]]
- อธิบายบทบาทของ Metadata / Lineage / Semantic Layer ต่อความน่าเชื่อถือ
