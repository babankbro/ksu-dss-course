# 7. เจาะลึกตารางมิติ (Dimension Tables)

หาก Fact Table เป็นตัวเลขในตาราง Excel **Dimension Table (ตารางมิติ)** ก็เปรียบเสมือน "ป้ายกำกับ (Labels)" ที่เอาไว้ตั้งเป็นแกน X และแกน Y ในการวาดกราฟ หากไม่มี Dimension ตัวเลขยอดขาย 10 ล้านบาทก็เป็นเพียงตัวเลขลอยๆ ที่ไม่มีใครรู้ว่ามาจากลูกค้ากลุ่มใด

## 7.1 ความสำคัญของมิติ (The Soul of the Data Warehouse)
Dimension Table เก็บแอตทริบิวต์เชิงพรรณนา (Descriptive Attributes) ที่ใช้สำหรับ:
* **Filtering (การกรองข้อมูล):** เช่น ขอดูเฉพาะสาขา "เชียงใหม่"
* **Grouping (การจัดกลุ่ม):** เช่น ขอดูยอดขายแยกตาม "หมวดหมู่สินค้า"
* **Labeling (การติดป้ายชื่อ):** แสดงชื่อลูกค้าแทนที่จะแสดงแค่รหัส

ลักษณะของ Dimension Table มักจะ "อ้วนแต่สั้น" คือมีคอลัมน์เยอะมาก (อาจมีถึง 50-100 คอลัมน์) เพื่อรองรับมุมมองการวิเคราะห์ทุกรูปแบบ แต่มีจำนวนบรรทัดน้อยกว่า Fact Table มาก

## 7.2 Surrogate Keys (กุญแจตัวแทน)
กฎเหล็กในการทำ Dimension Table คือ **ห้ามใช้รหัสจากระบบต้นทาง (Natural Key) เป็น Primary Key ในคลังข้อมูลเด็ดขาด** แต่ต้องสร้างคีย์ตัวแทน (Surrogate Key) ขึ้นมาใหม่ ซึ่งมักเป็นตัวเลขรันอัตโนมัติ (1, 2, 3...)
* **ทำไมถึงต้องสร้างใหม่?** 
  - ถ้าระบบ HR เปลี่ยนรหัสพนักงานใหม่ยกแผง ฐานข้อมูลคลังเราจะพังทันที 
  - ถ้าระบบ 2 สาขา รันรหัสซ้ำกัน (สาขา A มีรหัส C001, สาขา B ก็มีรหัส C001) การนำข้อมูลมารวมกันจะทับกัน 
  - การใช้ตัวเลข Integer ล้วนๆ ทำให้คอมพิวเตอร์ Join ตารางได้เร็วกว่าตัวอักษร

## 7.3 Date Dimension (มิติแห่งเวลา)
ทุกๆ Data Warehouse ต้องมีตารางที่ชื่อว่า `Dim_Date` เสมอ โดย 1 บรรทัดคือ "1 วันในปฏิทิน" 
* แทนที่ Fact Table จะบอกว่าเกิดยอดขายวันที่ "2023-12-25" เราจะชี้มาที่ Dim_Date ซึ่งมีข้อมูลบอกละเอียดว่า วันนี้คือ "วันคริสต์มาส (Holiday_Flag = Yes)", "อยู่ในไตรมาสที่ 4", "เป็นสัปดาห์ที่ 52 ของปี" 
* การมี Date Dimension ทำให้ผู้บริหารสามารถสั่ง Pivot ยอดขายดูเฉพาะ "ยอดวันหยุดนักขัตฤกษ์เทียบกับวันทำงาน" ได้ทันที โดยไม่ต้องเขียนโค้ดคำนวณวันหยุดเอง

## 7.4 Conformed Dimensions (มิติที่ตกลงร่วมกัน)
หากองค์กรต้องการเอา "ยอดขายของฝ่าย Sales" มาหารกับ "ค่าโฆษณาของฝ่าย Marketing" ตาราง Fact ของทั้งสองฝ่ายจะต้องใช้ **Dimension เดียวกัน (Conformed Dimension)**
* เช่น ต้องใช้ `Dim_Date` ตารางเดียวกัน และ `Dim_Product` ตารางเดียวกัน
* หากฝ่ายขายใช้รหัสสินค้าชุดนึง ฝ่ายการตลาดใช้รหัสอีกชุดนึง ระบบ DSS ของผู้บริหารก็จะไม่สามารถเทียบความคุ้มค่าของการทำโฆษณาต่อยอดขายระดับชิ้นได้เลย
