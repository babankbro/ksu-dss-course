# 9. อัลกอริทึมจำแนกประเภท: Naive Bayes (เบย์จอมซื่อบื้อ)

Naive Bayes เป็นอัลกอริทึมที่แตกต่างจาก Decision Tree อย่างสิ้นเชิง มันไม่ได้สร้างกฎ Yes/No แต่ทำงานด้วย **"ทฤษฎีความน่าจะเป็น (Probability)"** ของคุณทอมัส เบย์ส (Thomas Bayes)

## 9.1 Bayes' Theorem (ทฤษฎีบทของเบย์ส)
สมการระดับโลก: $P(Y|X) \propto P(Y) \times \prod P(X_i|Y)$
แปลเป็นภาษามนุษย์: 
* $P(Y)$: **Prior (ความเชื่อตั้งต้น)** เช่น ก่อนเห็นข้อมูลใดๆ เรารู้ว่าสถิติคนทุจริตในระบบคือ 1%
* $P(X_i|Y)$: **Likelihood (ความน่าจะเป็นของหลักฐาน)** เช่น ถ้าคนนั้นเป็นโจร (Y) โอกาสที่เขาจะ "รูดบัตรตอนตี 3 (X1)" เป็นเท่าไร? และโอกาสที่เขาจะ "ซื้อทองคำ (X2)" เป็นเท่าไร?
* $P(Y|X)$: **Posterior (ความเชื่อที่อัปเดตแล้ว)** เมื่อนำสถิติหลักฐานมาคูณกับความเชื่อตั้งต้น เราจะได้เปอร์เซ็นต์ฟันธงว่า "คนที่รูดบัตรตอนตี 3 และซื้อทองคำคนนี้ น่าจะเป็นโจร 95%!"

## 9.2 ทำไมถึงชื่อว่า "Naive (ซื่อบื้อ / ไร้เดียงสา)"?
อัลกอริทึมนี้มีข้อสมมติฐานที่ค่อนข้างไร้เดียงสาว่า **"ฟีเจอร์ทุกตัว ไม่มีความเกี่ยวข้องกันเลย (Conditionally Independent)"**
* ในความจริง "อายุ" กับ "เงินเดือน" มักจะเกี่ยวข้องกัน 
* แต่ Naive Bayes ไม่สนใจ มันจับทุกฟีเจอร์มาคูณกันดื้อๆ เลย
* ฟังดูเหมือนจะทำงานได้แย่ แต่ในทางปฏิบัติ (โดยเฉพาะงานแบ่งประเภทข้อความ) มันกลับทำงานได้แม่นยำอย่างเหลือเชื่อ!

## 9.3 สายพันธุ์ของ Naive Bayes
เลือกใช้ให้ถูกกับลักษณะข้อมูล:
1. **GaussianNB:** ใช้เมื่อคอลัมน์ของคุณเป็น "ตัวเลขทศนิยม" (เช่น เงินเดือน, ส่วนสูง) โมเดลจะทึกทักว่าข้อมูลของคุณกระจายตัวแบบระฆังคว่ำ (Normal Distribution)
2. **MultinomialNB:** ใช้กับข้อมูลที่ตารางเป็น "การนับจำนวน (Counts)" เช่น การนับจำนวนคำว่า "ฟรี" "ด่วน" "แจก" ในอีเมล 
   - *(เป็นราชาแห่งการกรอง Spam Email ตลอดกาล)*
3. **BernoulliNB:** ใช้เมื่อฟีเจอร์ทุกตัวของคุณเป็นแค่ `0 กับ 1` (เช่น มีคำนี้ = 1, ไม่มี = 0)

## 9.4 จุดแข็งและจุดอ่อน
* **จุดแข็ง:** 
  - ทำงานรวดเร็วระดับปิศาจ (เร็วที่สุดในบรรดาอัลกอริทึมทั้งหมด) 
  - ใช้ RAM น้อยมาก เพราะแค่หาค่าสถิติมาคูณกันเฉยๆ
  - เป็นโมเดลตั้งต้น (Baseline) ที่ดีมาก 
* **จุดอ่อน:** 
  - กฎที่ว่า "ฟีเจอร์ไม่เกี่ยวข้องกัน" มักทำให้ตัวเลข % Probability ที่คำนวณออกมา ทะลุเกินจริง (Overconfident) เช่น ทายว่าจะเป็นโจร 99.999% 
  - การนำ % probability จาก Naive Bayes ไปใช้งานตัดสินใจความเสี่ยงทางการเงินโดยตรง อาจต้องทำการดัด (Calibration) กราฟให้ตรงกับความเป็นจริงเสียก่อน
