# 1. Data Mining ในระบบสนับสนุนการตัดสินใจ (DSS)

เมื่อเรามี Data Warehouse ที่สมบูรณ์แบบเพื่อดูรายงานย้อนหลังผ่าน OLAP (Online Analytical Processing) แล้ว คำถามต่อไปที่ผู้บริหารมักจะถามคือ **"แล้วพรุ่งนี้จะเกิดอะไรขึ้นล่ะ?"** นี่คือจุดที่วิชา Data Mining (การทำเหมืองข้อมูล) ก้าวเข้ามามีบทบาทในระบบ DSS

## 1.1 ตำแหน่งของ Data Mining ในสถาปัตยกรรม DSS
Data Mining คือการใช้ข้อมูล (Data) ก้อนใหญ่ ผสานเข้ากับแบบจำลองทางคณิตศาสตร์ (Model) เพื่อค้นหารูปแบบ (Pattern) หรือทำนายผลลัพธ์ (Prediction) ที่ยังไม่เกิดขึ้น ในสถาปัตยกรรม DSS งานส่วนนี้จะแทรกตัวอยู่ตรงกลางระหว่าง 3 เสาหลัก:

1. **Data Management:** เป็นแหล่งวัตถุดิบ (ข้อมูลประวัติลูกค้า, บันทึกการทำธุรกรรม)
2. **Model Management:** เป็นพื้นที่สำหรับฝึกฝน (Train), ประเมิน (Evaluate), และจัดการเวอร์ชันของโมเดล Data Mining
3. **User Interface (UI):** เป็นด่านสุดท้ายที่แปล "ผลลัพธ์ทางสถิติ" ให้ออกมาเป็น "ทางเลือกที่มนุษย์เข้าใจได้ง่าย" (เช่น โชว์ป้ายกำกับสีแดงว่าลูกค้าคนนี้เสี่ยงหนี้สูญ)

## 1.2 งานหลักของ Data Mining
Data Mining แบ่งออกเป็น 4 กลุ่มงานหลัก แต่ละกลุ่มตอบสนองเป้าหมายทางธุรกิจที่ต่างกัน:
1. **Classification (การจำแนกประเภท):** ทำนาย "ป้ายกำกับ (Label)" เช่น ทำนายว่ารายการรูดบัตรนี้ "ปกติ" หรือ "ทุจริต" (เน้นเนื้อหาในสัปดาห์นี้)
2. **Regression (การทำนายค่าต่อเนื่อง):** ทำนาย "ตัวเลข" เช่น ลูกค้าคนนี้จะทำยอดซื้อรวมให้เรากี่บาทในชีวิตนี้ (Customer Lifetime Value)
3. **Clustering (การจัดกลุ่ม):** การหาเพื่อนที่มีลักษณะคล้ายกัน โดยที่ยังไม่รู้ว่ากลุ่มนั้นเรียกว่าอะไร เช่น การทำ Customer Segmentation
4. **Association Rules (กฎความสัมพันธ์):** การหาสินค้าที่มักถูกซื้อคู่กัน (Market Basket Analysis)

## 1.3 ความแตกต่างระหว่าง Data Mining และ OLAP
หลายคนมักสับสนสองคำนี้เพราะมันวิเคราะห์ข้อมูลก้อนเดียวกัน:
* **OLAP (อดีต):** เป็น "Descriptive" บอกว่าเกิดอะไรขึ้น (เช่น ยอดขายภาคเหนือตก 10%) มนุษย์เป็นคนลงมือหมุนหน้าจอ (Slice & Dice) เพื่อหาคำตอบด้วยตัวเอง
* **Data Mining (อนาคต):** เป็น "Predictive" ทำนายสิ่งที่อาจจะเกิด (เช่น ปัจจัยอะไรบ้างที่บอกว่าลูกค้าภาคเหนือจะหนีไปใช้ค่ายอื่น?) อัลกอริทึมจะเป็นคนเรียนรู้และหากฎนั้นให้มนุษย์

ระบบ DSS ที่ทรงพลังที่สุดคือระบบที่ใช้ทั้งสองอย่างร่วมกัน: ใช้ OLAP เพื่อตรวจสอบสถานการณ์ปัจจุบัน และใช้ Data Mining เพื่อจัดลำดับความเสี่ยงให้ทีมงานออกไปทำงานล่วงหน้า (Proactive)
