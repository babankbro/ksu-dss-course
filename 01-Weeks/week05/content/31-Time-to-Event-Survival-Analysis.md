# 31. ข้ามขีดจำกัด Classification ด้วย Survival Analysis (Time-to-Event)

โจทย์ Classification เรื่อง Churn (ลูกค้าเลิกใช้บริการ) มักตั้งคำถามว่า "ลูกค้าคนนี้จะหนีเราไป ภายใน 30 วันนี้ หรือไม่? (Yes/No)"
* **ข้อจำกัด:** ถ้าเขาไม่ได้หนีใน 30 วัน แต่อาจจะหนีในวันที่ 32 ล่ะ? แล้วเราควรจะรอทำไม? ทำไมไม่ทำนาย "ระยะเวลา" ไปเลยว่าเขาจะอยู่กับเราอีกกี่วัน?
* **ทางแก้ทางเลือก:** งั้นใช้ Regression ทำนาย "จำนวนวัน" (เช่น 120 วัน) สิ? 
* **พังอีก!:** เพราะลูกค้าบางคนยังใช้งานอยู่ (ยังไม่เลิก) เราไม่รู้จำนวนวันสิ้นสุดที่แท้จริงของเขา (ปรากฏการณ์นี้เรียกว่า **Censored Data** หรือข้อมูลที่ยังตายไม่สุด) Regression จะพังทันทีถ้าเจอข้อมูลแบบนี้

นี่คือเหตุผลที่วิชา **Survival Analysis (การวิเคราะห์การรอดชีวิต)** ซึ่งถูกคิดค้นในวงการแพทย์ (คำนวณวันตายของผู้ป่วย) ถูกนำมาใช้ในวงการธุรกิจเพื่อทำนายการ Churn

## 31.1 Kaplan-Meier Curve (กราฟแห่งอายุขัย)
* ไม่ต้องมี Machine Learning ก็วาดได้!
* เป็นการพล็อตกราฟขั้นบันได แกน X คือ "วันนับตั้งแต่สมัคร", แกน Y คือ "เปอร์เซ็นต์คนที่ยังอยู่รอด"
* พอเราเอา กราฟของ "คนจ่ายผ่านบัตรเครดิต" มาซ้อนทับกับ "คนจ่ายผ่านบิล" 
* เราจะเห็นด้วยตาเปล่าเลยว่า คนกลุ่มไหนมี "อายุขัยเฉลี่ย (Median Survival Time)" ในระบบนานกว่ากัน (เป็นเครื่องมือชั้นยอดสำหรับนำเสนอผู้บริหาร)

## 31.2 Cox Proportional Hazards Model
* เป็น Machine Learning สมัยปู่ (แนวสถิติ) ที่คลาสสิกและอธิบายเหตุผลได้ดีมาก
* ไม่ได้ทำนาย 0 หรือ 1 แต่ทำนาย **"Hazard Ratio (อัตราส่วนความเสี่ยง)"**
* **สมการอธิบายว่า:** `อายุเพิ่ม 1 ปี = เสี่ยงหนีเพิ่ม 1.2 เท่า` / `เปิดใช้ Auto-pay = ความเสี่ยงหนีลดลง 0.5 เท่า`
* ทรงพลังมากเพราะมันอธิบายปัจจัยกระตุ้นให้ลูกค้าอยู่ต่อหรือจากไปได้อย่างเป็นระบบ

## 31.3 โมเดลยุคใหม่ (Survival Forests & DeepSurv)
* ปัจจุบัน Data Scientist จับหลักการ Survival ไปใส่ใน Random Forest (กลายเป็น Survival Forest) หรือใส่ Neural Networks (DeepSurv) 
* **ผลลัพธ์บนหน้าจอ DSS:** พนักงานคอลเซ็นเตอร์จะไม่เห็นแค่ "ความเสี่ยง = 80%" แต่จะเห็น **"กราฟอายุขัยรายบุคคล"** พนักงานจะรู้ทันทีว่า "ถ้าเรายื่นโปรโมชั่น A ให้ลูกค้า กราฟอายุขัยของเขาจะยืดออกไปอีก 6 เดือน!" (นี่คือ Prescriptive Analytics ของแท้)
