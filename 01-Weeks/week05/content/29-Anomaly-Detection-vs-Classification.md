# 29. เมื่อหาคนทุจริตไม่เจอ: Anomaly Detection vs Classification

เราพร่ำบอกมาตลอดว่า Classification ต้องใช้ข้อมูลอดีตมาฝึก (เช่น ต้องมีโจรให้โมเดลดูเป็นตัวอย่างก่อน)
*คำถามโลกแตก:* "แล้วถ้าเราเป็นธนาคารเปิดใหม่เอี่ยม เปิดมา 3 วัน ยังไม่เคยโดนแฮกเลย (ไม่มีโจรเลยสักคน) เราจะสร้างโมเดลกันขโมยได้อย่างไร!?"

นี่คือจุดตัดที่ต้องเปลี่ยนจากวิชา **Classification (Supervised)** ไปเป็นวิชา **Anomaly Detection (Unsupervised)**

## 29.1 ปรัชญาที่ต่างกัน
* **Classification (หาคนที่หน้าเหมือนโจร):** ต้องมีรูปโจรให้ดูเป็นตัวอย่าง ถ้าแฮกเกอร์ใช้มุกใหม่ที่ไม่เคยมีในฐานข้อมูล โมเดลนี้จะใบ้กินทันที
* **Anomaly Detection (หาคนที่หน้าแปลกประหลาด):** ไม่ต้องรู้ว่าโจรหน้าตาเป็นอย่างไร มันเรียนรู้แค่ว่า "คนปกติเขาทำตัวกันยังไง (Normality)" ถ้าใครทำตัวนอกคอกไปจากมาตรฐาน ถือว่าเป็นพวกน่าสงสัยทั้งหมด! (เก่งมากในการจับแฮกเกอร์สายพันธุ์ใหม่ Zero-day Attack)

## 29.2 อัลกอริทึมปราบมาร: Isolation Forest
หลักการของ Isolation Forest (ป่าสุ่มแยกเดี่ยว) นั้นเรียบง่ายแต่มหัศจรรย์มาก:
1. คอมพิวเตอร์จะสุ่มขีดเส้นตรงตัดแบ่งข้อมูล (หั่นแกน X บ้าง แกน Y บ้าง) ไปเรื่อยๆ 
2. เป้าหมายคือ "หั่นจนกว่าทุกคนจะถูกกักบริเวณอยู่คนเดียว (Isolated)"
3. **การให้คะแนนความแปลกประหลาด (Anomaly Score):**
   - ถ้าคนไหน "แปลกแยก" สุดๆ (ยืนอยู่ไกลจากชาวบ้าน) คอมพิวเตอร์ขีดเส้นตรงหั่นแค่ 2-3 ครั้ง ก็แยกหมอนี่ออกมาโดดๆ ได้แล้ว (ได้สกอร์ความแปลก = สูง)
   - ถ้าคนไหนเป็น "คนปกติ" (กระจุกตัวกันแน่นอยู่ตรงกลาง) คอมพิวเตอร์ต้องขีดเส้นหั่นถี่ยิบเป็น 20-30 ครั้ง กว่าจะแยกคนนี้ออกมาอยู่คนเดียวได้ (ได้สกอร์ความแปลก = ต่ำ)

## 29.3 One-Class SVM (ตีเส้นล้อมคอก)
* คล้ายกับ SVM ที่แบ่งเขตแดนในบทที่ 15
* แต่ One-Class SVM จะไม่มีจุดสีแดง (โจร) ให้มันดู
* มันจะนำจุดสีน้ำเงิน (คนปกติ) ทั้งหมด โยนลงไปบนกระดาษ แล้วใช้ไม้บรรทัดโค้งๆ วงกลมล้อมรั้วคนสีน้ำเงินให้แน่นที่สุด
* ทันทีที่มีคนใหม่เข้ามา (จุดสีเขียว) ถ้ายืนอยู่ในรั้ว = รอด, ถ้ายืนอยู่นอกรั้ว = สั่งแบน!

**ข้อควรระวังในการใช้งาน:** Anomaly Detection มักจะพ่น **False Positive** ออกมามหาศาล เพราะคนปกติบางคนก็แค่เป็นเศรษฐีใช้เงินเยอะ (ไม่ได้แปลกประหลาดทางอาชญากรรม) ในระบบ DSS จึงมักใช้ Anomaly Detection เป็นตัวกรองด่านแรก ควบคู่กับ Classification ในด่านที่สอง
