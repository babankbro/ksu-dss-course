# 34. เลิกเดาด้วย A/B Testing (การประเมินโมเดลบนโลกออนไลน์)

ในห้องทดลอง Data Scientist อาจจะคุยโวว่า "โมเดลเวอร์ชัน 2.0 (XGBoost) ของฉัน มีค่า F1-Score สูงกว่าเวอร์ชัน 1.0 (Decision Tree) ตั้ง 10% เอาขึ้นระบบเลยเจ้านาย!"

แต่นักธุรกิจที่เก๋าเกมจะไม่ยอมปล่อยให้โมเดลใหม่ 100% ไปทับโมเดลเก่าทันที เพราะคะแนนในห้องแล็บ (Offline Evaluation) มักไม่ได้สะท้อนความจริงบนโลกออนไลน์ (Online Evaluation)

## 34.1 การสับสวิตช์แบบ A/B Testing
แทนที่จะเปลี่ยนระบบทั้งหมด เราจะใช้วิธี **A/B Testing**
1. โมเดล V.1 (ของเก่า) = ให้เป็นกลุ่มควบคุม (Control Group)
2. โมเดล V.2 (ของใหม่) = ให้เป็นกลุ่มทดลอง (Treatment Group)
3. **ตัวแบ่งการจราจร (Traffic Splitter):** เมื่อลูกค้ากดเข้าเว็บ หรือกดขอสินเชื่อ ระบบตัวกลางจะสุ่มโยนลูกค้า:
   - ลูกค้า 90% แรก ถูกส่งไปหาโมเดล V.1 (เพื่อรับประกันว่าถ้าระบบใหม่พัง บริษัทก็ไม่เจ๊ง)
   - ลูกค้า 10% ถูกส่งไปหาโมเดล V.2 (หนูทดลอง)
4. ปล่อยระบบทิ้งไว้ 2-4 สัปดาห์

## 34.2 การวัดผลด้วยค่าทางสถิติ (Statistical Significance)
สมมติว่าครบ 1 เดือน:
* กลุ่ม V.1 มีอัตราการเบี้ยวหนี้ 5%
* กลุ่ม V.2 มีอัตราการเบี้ยวหนี้ 4.5%

เราจะด่วนสรุปว่า V.2 เก่งกว่าได้ไหม? **คำตอบคือ ยังไม่ได้!** 
ความต่าง 0.5% นี้ อาจจะเกิดจากความฟลุค (Chance) ที่โมเดล V.2 บังเอิญสุ่มเจอลูกค้ารวยๆ พอดี เราต้องนำผลลัพธ์เข้าสู่สมการทดสอบสมมติฐานทางสถิติ (เช่น T-test หรือ Chi-Square) เพื่อคำนวณหาค่า **p-value**
* ถ้า p-value < 0.05 (แปลว่าโอกาสฟลุคน้อยกว่า 5%) เราจึงจะสามารถเดินไปบอก CEO ได้เต็มปากว่า "โมเดล V.2 ชนะอย่างมีนัยสำคัญทางสถิติ" และกดขยาย Traffic จาก 10% ให้เป็น 100% ทั่วประเทศได้

## 34.3 Multi-Armed Bandits (สล็อตแมชชีนหลายแขน)
A/B Testing มีข้อเสียคือ "ต้องรอ" นานเป็นเดือน และยอมให้ลูกค้า 10% ได้รับบริการห่วยๆ (ถ้า V.2 มันห่วยจริง)
วงการ DSS ยุคใหม่จึงเปลี่ยนมาใช้ AI ที่ฉลาดกว่า เรียกว่า **Multi-Armed Bandit**
* อัลกอริทึมนี้จะปล่อยโมเดล 3-4 ตัวลงไปแข่งกันพร้อมๆ กัน
* ในช่วงวันแรกๆ มันจะสุ่มโยนลูกค้าให้ทุกคนเท่าๆ กัน
* พอผ่านไป 2-3 วัน มันเริ่มสังเกตเห็นว่า "เฮ้ย โมเดล B ทำกำไรได้เยอะกว่าว่ะ"
* มันจะ **"แอบปรับเปลี่ยนทราฟฟิกอัตโนมัติ (Dynamic Routing)"** โดยค่อยๆ โยกยอดลูกค้าไปหาโมเดล B มากขึ้นเรื่อยๆ โดยที่มนุษย์ไม่ต้องนั่งรอจบเดือน!
เทคนิคนี้คือหัวใจสำคัญที่ Amazon, Netflix, และ TikTok ใช้เพื่อรีดเร้นกำไรสูงสุดแบบวินาทีต่อวินาที
