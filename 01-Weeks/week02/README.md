# Week 02 — DSS Architecture

ชุดสอนฉบับขยายเรื่องสถาปัตยกรรมและระบบย่อยของระบบสนับสนุนการตัดสินใจ (DSS) ออกแบบสำหรับบรรยาย 2 ชั่วโมงและปฏิบัติการ 2 ชั่วโมง

## ผลลัพธ์การเรียนรู้

เมื่อจบบทเรียน ผู้เรียนควรสามารถ:

1. อธิบายหน้าที่ของ Data, Model, Knowledge และ User Interface subsystems
2. ติดตามเส้นทางข้อมูลตั้งแต่แหล่งข้อมูลจนถึงคำแนะนำและการลงมือทำ
3. จำแนก DSS ตามกรอบของ Power และอธิบายว่าเหตุใดระบบจริงจึงมักเป็น hybrid
4. เลือกสถาปัตยกรรม batch/real-time และ cloud/edge ให้เหมาะกับบริบท
5. วิเคราะห์ความเสี่ยง จุดล้มเหลว และกลไกกำกับดูแลของ DSS
6. ออกแบบ Future DSS ที่มี agent orchestration, monitoring และ human oversight
