# 19. สถาปัตยกรรมแบบ Cloud-Native และ Microservices ใน DSS

ในอดีต ระบบ DSS ถูกสร้างขึ้นมาเป็น "ก้อนเดียว (Monolithic)" ซึ่งรวมเอาการจัดการข้อมูล โมเดล และหน้าจอเว็บมาเขียนรวมไว้ในโค้ดชุดเดียวกันบนเซิร์ฟเวอร์เดียว แต่เมื่อข้อมูลมีขนาดใหญ่ขึ้นมหาศาล สถาปัตยกรรมยุคใหม่จึงเปลี่ยนผ่านเข้าสู่ยุค **Cloud-Native** อย่างเต็มรูปแบบ

## 19.1 แนวคิด Microservices (ไมโครเซอร์วิส)
สถาปนิกจะซอยระบบ DSS ออกเป็น "บริการชิ้นเล็กๆ (Microservices)" ที่ทำงานแยกกันอย่างอิสระ:
* **Service A:** ทำหน้าที่ดูดข้อมูลพยากรณ์อากาศ 
* **Service B:** ทำหน้าที่รันโมเดลทำนายอุปสงค์ 
* **Service C:** ทำหน้าที่เช็คเครดิตลูกค้า

**ข้อดีที่เหนือกว่า:**
1. **การขยายขนาด (Scalability):** วันที่มีโปรโมชั่นคนเข้าเว็บเยอะ ระบบสามารถสั่ง "ก๊อปปี้เพิ่มเฉพาะ Service B" ให้รับโหลดไหว โดยไม่ต้องก๊อปปี้ทั้งก้อน ทำให้ประหยัดค่าเซิร์ฟเวอร์
2. **ความยืดหยุ่น (Resilience):** หาก Service A ล่ม ระบบจะไม่พังทั้งหมด ผู้ใช้ยังสามารถเช็คเครดิตลูกค้า (Service C) ต่อไปได้
3. **การพัฒนาที่แยกขาด:** ทีม Data Scientist ทำงานกับ Service B (เขียนด้วย Python) ส่วนทีม Web Developer ทำงานกับ Service C (เขียนด้วย Node.js) โดยไม่ตีกัน

## 19.2 เทคโนโลยี Containers และ Kubernetes
เพื่อให้ Microservices เหล่านี้ทำงานบนคลาวด์ได้อย่างราบรื่น:
* **Containers (เช่น Docker):** เป็นการบรรจุโมเดลและโปรแกรมลงในกล่องจำลอง เพื่อให้มั่นใจได้ว่า "รันบนเครื่องโปรแกรมเมอร์ได้ ก็ต้องรันบนเซิร์ฟเวอร์บริษัทได้แบบไม่ผิดเพี้ยน"
* **Kubernetes (K8s):** เปรียบเสมือน "ผู้จัดการท่าเรือ" ที่คอยคุมตู้คอนเทนเนอร์ (Containers) นับร้อยตู้ หากตู้ไหนพัง K8s จะรีบูตใหม่ให้อัตโนมัติ หากมีพายุเข้ามา (ทราฟฟิกข้อมูลพุ่ง) K8s จะสั่งเปิดตู้เพิ่มอัตโนมัติ

## 19.3 Serverless DSS (การไร้เซิร์ฟเวอร์)
ก้าวต่อไปของ Cloud-Native คือการที่องค์กร **"ไม่ต้องเช่าเซิร์ฟเวอร์ทิ้งไว้เลย"** (Serverless Computing เช่น AWS Lambda)
* เมื่อไรที่ไม่มีพนักงานคนไหนกดวิเคราะห์ข้อมูล ระบบหลังบ้านจะปิดตัวลงเป็นศูนย์ (จ่ายค่าไฟ $0)
* ทันทีที่ผู้บริหารคลิกปุ่ม "ประเมินความเสี่ยง" โค้ดจะถูกปลุกขึ้นมาทำงานภายในเสี้ยววินาที คิดเงินเฉพาะเสี้ยววินาทีนั้น แล้วก็ปิดตัวเองลง 
* สถาปัตยกรรมนี้เหมาะมากกับ DSS เชิงกลยุทธ์ (Strategic DSS) ที่ผู้บริหารระดับสูงนานๆ จะกดเข้ามาดูสักครั้ง ช่วยลดต้นทุน (Cost Optimization) ให้องค์กรได้อย่างมหาศาล
