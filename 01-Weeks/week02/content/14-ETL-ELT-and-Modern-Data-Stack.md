# 14. ท่อส่งข้อมูลและเครื่องมือสถาปัตยกรรมสมัยใหม่ (The Modern Data Stack for DSS)

สถาปัตยกรรมข้อมูล (Data Management Subsystem) จะไม่สามารถมีชีวิตขึ้นมาได้หากขาดเครื่องมือ (Tools) ในปัจจุบัน การเขียนโปรแกรมย้ายข้อมูลเองบรรทัดต่อบรรทัดถือว่าล้าสมัยไปแล้ว องค์กรนิยมใช้สิ่งที่เรียกว่า **Modern Data Stack (MDS)**

## 14.1 การเปลี่ยนผ่านจาก ETL สู่ ELT
* **ETL (Extract -> Transform -> Load):** ในอดีต ฐานข้อมูลปลายทางมีราคาแพงและประมวลผลช้า จึงต้องสกัดข้อมูล (Extract) ออกมาทำความสะอาดและแปลงรูป (Transform) ที่เซิร์ฟเวอร์ตรงกลางก่อน แล้วค่อยโหลด (Load) เข้าโกดังข้อมูล
* **ELT (Extract -> Load -> Transform):** ปัจจุบัน Cloud Data Warehouse (เช่น Snowflake, Google BigQuery) มีพลังคำนวณที่มหาศาลและราคาถูกลง สถาปนิกจึงนิยมดูดข้อมูลดิบทั้งหมด โหลดเข้า Cloud ก่อน (Load) แล้วค่อยไปเขียนคำสั่ง SQL ทำความสะอาดข้อมูลบน Cloud นั้นเลย (Transform) วิธีนี้ช่วยรักษาข้อมูลต้นฉบับไว้ทั้งหมด

## 14.2 เครื่องมือสำคัญใน Modern Data Stack
การสร้างท่อส่งข้อมูลสำหรับ DSS มักจะประกอบด้วยเครื่องมือตามหน้าที่ ดังนี้:

**1. Data Ingestion (เครื่องมือดูดข้อมูล):**
* ทำหน้าที่สกัดข้อมูลจากแหล่งต่างๆ (เช่น โซเชียลมีเดีย, ไฟล์ Excel, ฐานข้อมูลเดิม) โดยไม่ต้องเขียนโค้ด
* **ตัวอย่างซอฟต์แวร์:** Fivetran, Airbyte, Stitch

**2. Data Storage / Cloud Data Warehouse (คลังข้อมูลคลาวด์):**
* แหล่งพักพิงสุดท้ายที่ใช้เก็บข้อมูลมหาศาล รองรับการดึงข้อมูล (Query) วิเคราะห์พร้อมๆ กันนับพันคน
* **ตัวอย่างซอฟต์แวร์:** Snowflake, Google BigQuery, Amazon Redshift

**3. Data Transformation (เครื่องมือแปลงรูปข้อมูล):**
* หลังจากข้อมูลดิบไหลเข้าคลัง จะใช้เครื่องมือเหล่านี้รันคำสั่ง SQL สร้างตารางข้อมูลให้พร้อมวิเคราะห์ (เช่น เอาตารางยอดขายไปต่อกับตารางชื่อพนักงาน)
* **ตัวอย่างซอฟต์แวร์:** dbt (data build tool) ซึ่งปัจจุบันเป็นมาตรฐานทองคำของวงการ

**4. Data Orchestration (ตัวควบคุมจังหวะการทำงาน):**
* เปรียบเสมือนผู้จัดการตารางงาน (Scheduler) คอยสั่งว่า "ตี 1 ให้เริ่มดูดข้อมูล ตี 2 ให้เริ่มแปลงรูป ตี 3 ให้แจ้งเตือนถ้าเกิด Error"
* **ตัวอย่างซอฟต์แวร์:** Apache Airflow, Dagster, Prefect

การประกอบเครื่องมือเหล่านี้เข้าด้วยกัน ช่วยให้ DSS มีท่อส่งข้อมูลที่ทรงพลัง ทำงานอัตโนมัติ 100% และลดความเสี่ยงจากมนุษย์ (Human Error) ได้อย่างสิ้นเชิง
