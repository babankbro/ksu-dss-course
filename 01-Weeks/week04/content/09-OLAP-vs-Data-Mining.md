# 9. การทำงานร่วมกันระหว่าง OLAP และ Data Mining (เหมืองข้อมูล)

ผู้บริหารและนักศึกษาหลายคนมักสับสนระหว่างสองคำนี้ เพราะทั้งคู่ทำหน้าที่ "วิเคราะห์ข้อมูลขนาดใหญ่" เหมือนกัน แต่แท้จริงแล้ว สองระบบนี้มีปรัชญาการทำงานที่แตกต่างกันอย่างสิ้นเชิง และควรนำมาใช้งานเกื้อหนุนกัน (Complementary)

## 9.1 ความแตกต่างเชิงปรัชญา

| ประเด็นเปรียบเทียบ | OLAP (การประมวลผลเชิงวิเคราะห์ออนไลน์) | Data Mining (การทำเหมืองข้อมูล) |
|---|---|---|
| **ผู้ขับเคลื่อน (Driver)** | **มนุษย์เป็นผู้ตั้งคำถาม** (User-driven) | **อัลกอริทึมเป็นผู้ค้นหา** (Data-driven) |
| **จุดประสงค์** | บอกว่า "เกิดอะไรขึ้น? ที่ไหน? เมื่อไร?" (Descriptive / Diagnostic) | บอกว่า "อะไรจะเกิดขึ้น? ทำไมถึงเกิด? มีรูปแบบอะไรซ่อนอยู่?" (Predictive / Discovery) |
| **ตัวอย่างคำถาม** | "ยอดขายในภาคเหนือลดลงในเดือนที่แล้วเท่าไร?" | "ปัจจัยอะไรที่พยากรณ์ว่าลูกค้าภาคเหนือจะเลิกซื้อสินค้าเรา?" |
| **วิธีการทำงาน** | ผู้ใช้กด Drill-down, Slice, Dice ไปเรื่อยๆ จนเจอจุดผิดปกติ | โยนข้อมูลลงไปให้ AI วิ่งหารูปแบบ (Pattern) กฎความสัมพันธ์ หรือจัดกลุ่มลูกค้าให้เอง |
| **การตรวจสอบย้อนหลัง** | ตรวจสอบได้ชัดเจน 100% เพราะอิงจากการบวกเลขตามยอดจริง | ตรวจสอบยาก ต้องวัดค่าความเชื่อมั่นทางสถิติ (Accuracy, Precision, Recall) |

## 9.2 สองประสาน: การทำงานร่วมกันแบบไร้รอยต่อ
องค์กรที่แข็งแกร่งจะไม่เลือกใช้อย่างใดอย่างหนึ่ง แต่จะสร้างท่อการทำงานวงจรปิด (Closed-loop workflow) ดังนี้:

**Step 1: ใช้ OLAP ค้นหาสัญญาณเตือนภัย (Diagnostic)**
* ผู้บริหารเปิด OLAP Dashboard แล้วใช้ทักษะ (Intuition) ของมนุษย์ เจาะลึกลงไป (Drill-down) จนพบว่า *"กลุ่มลูกค้าวัยรุ่นในสาขาชานเมือง มีอัตราการคืนสินค้าเพิ่มขึ้น 15%"* 
* OLAP บอกได้แค่นี้ แต่มันหาเหตุผลไม่ได้ว่า "ทำไม?"

**Step 2: ส่งต่อให้ Data Mining หารูปแบบ (Discovery)**
* สกัดข้อมูลลูกค้ารายบุคคลในกลุ่มนั้น ส่งให้ Data Scientist รันโมเดล Data Mining (เช่น Decision Tree หรือ Association Rule)
* AI ค้นพบว่า *"ลูกค้าที่ซื้อสินค้า A คู่กับสินค้า B ในช่วงเย็น มักจะนำมาคืน 80% เพราะบรรจุภัณฑ์สองชิ้นนี้มันเสียดสีกันตอนขนส่งทำให้ของพัง"* (ซึ่งมนุษย์ไม่มีวันหากฎนี้เจอเองจากการหมุน Cube)

**Step 3: นำกฎกลับไปตั้งรับใน OLAP (Tracking)**
* เมื่อเจอปัญหา บริษัทปรับปรุงบรรจุภัณฑ์ 
* จากนั้น นำตัวชี้วัด (Metrics) ที่ Data Mining ค้นพบเมื่อกี้ กลับไปสร้างเป็นมาตรวัดอันใหม่บน OLAP Dashboard เพื่อให้ผู้บริหารติดตามแบบสัปดาห์ต่อสัปดาห์ ว่าอัตราการคืนสินค้าคู่นี้ลดลงหรือไม่

**สรุป:** OLAP เป็นเสมือน "กล้องส่องทางไกล" ที่ให้มนุษย์กวาดสายตาหาเป้าหมาย ส่วน Data Mining เป็นเสมือน "กล้องจุลทรรศน์อัจฉริยะ" ที่ซูมเจาะลึกทะลุเซลล์ลงไปหารูปแบบที่ตามนุษย์มองไม่เห็น
