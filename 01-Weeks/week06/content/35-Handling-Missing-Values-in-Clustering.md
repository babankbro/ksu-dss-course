# 35. การรับมือข้อมูลสูญหายใน Clustering (Missing Values)

ปัญหาคลาสสิกของชาว Data: ตารางลูกค้า 1 แสนคน แต่ปรากฏว่า "อายุ" หายไป 20% และ "รายได้" หายไป 30% 

ถ้าเป็น Classification เรายังพอใช้เทคนิค MICE (บทที่ 27) เติมค่าว่างได้ เพราะมันมี Label คอยควบคุมทิศทาง แต่ในโลกของ Unsupervised Learning การเติมค่าว่างแบบสุ่มสี่สุ่มห้า อาจจะเปลี่ยนรูปร่างของอวกาศข้อมูล (Topology) ไปจนพังพินาศ

## 35.1 ความวิบัติของการเติมค่าเฉลี่ย (Mean Imputation)
* ถ้ารายได้หายไป แล้วคุณสั่งคอมพิวเตอร์เติมคำว่า "25,000 บาท (ค่าเฉลี่ยประเทศ)" ลงไปในช่องว่างของทุกคน
* สิ่งที่จะเกิดขึ้นคือ จุดข้อมูลที่เคยกระจายตัวสวยงาม จะถูกกระชากมารวมตัวกันเป็น "เสาหินแท่งยักษ์" ตรงกลางแผนที่ (ตรงตำแหน่ง 25,000)
* K-Means จะถูกหลอกให้เอา Centroid ไปแปะที่เสาหินแท่งนั้น (เพราะคิดว่าโอ้โหตรงนี้คนหนาแน่นมาก!) 
* **ผลลัพธ์:** กลุ่มที่คุณได้ คือกลุ่มของ "คนที่บังเอิญลืมกรอกรายได้" ไม่ใช่กลุ่มพฤติกรรมการซื้อจริง! (นี่คือฝันร้ายของ DSS)

## 35.2 การจัดกลุ่มข้ามเงา (K-Means with Partial Distance)
วิธีที่ดีที่สุดคือ **"ไม่ต้องเติม!"** แต่ออกแบบคณิตศาสตร์ให้เก่งขึ้น
* เมื่อ K-Means ต้องคำนวณระยะห่างระหว่าง นาย ก. และ Centroid 
* ถ้านาย ก. ไม่มีค่า "รายได้" K-Means จะข้ามคอลัมน์นี้ไปเลย (ลบมิตินี้ทิ้งชั่วคราว) แล้วคำนวณระยะห่างเฉพาะคอลัมน์ที่เหลือ (Partial Euclidean Distance)
* จากนั้น นำระยะที่ได้ มาคูณชดเชย (Scale up) ด้วยสัดส่วนคอลัมน์ที่หายไป 
* วิธีนี้ (Soft-k-means หรือ K-POD algorithm) ทำให้โมเดลสามารถจัดกลุ่มข้อมูลแหว่งๆ ได้โดยไม่ต้องทำร้ายรูปทรงทางเรขาคณิตดั้งเดิม

## 35.3 กฎตะกร้าสินค้า (Apriori) กับข้อมูลแหว่ง
สำหรับ Association Rules ปัญหานี้ง่ายกว่ามาก
* ถ้าใบเสร็จพิมพ์หมึกจาง มองไม่เห็นว่าซื้ออะไรไป 1 ชิ้น เราก็แค่ "ข้าม" ชิ้นนั้นไปเลย!
* พลังของการหาแพทเทิร์นแบบ FP-Growth สนใจแค่ "สิ่งที่มีอยู่ (Positive presence)" ไม่ได้สนใจสิ่งที่ไม่มี (ต่างจากคณิตศาสตร์ระยะทางของ K-Means) ดังนั้น Missing Value แทบจะไม่กระทบการทำ Market Basket Analysis เลย
