# 1. การค้นพบรูปแบบ (Pattern Discovery) ≠ พร้อมตัดสินใจ

ในสัปดาห์ที่ 5 (Classification) โมเดลมีเป้าหมายชัดเจนว่าใครคือคนดีและใครคือโจร แต่ในสัปดาห์นี้ (Data Mining II) เราจะเข้าสู่โลกของ **Unsupervised Learning (การเรียนรู้แบบไม่มีผู้สอน)** ซึ่งไม่มีเฉลย (Label) ล่วงหน้า

เป้าหมายของ Unsupervised Learning คือการโยนข้อมูลดิบลงไป แล้วหวังว่าอัลกอริทึมจะหากลุ่ม (Clustering) หรือความสัมพันธ์ (Association Rules) ที่ซ่อนอยู่เจอ

## 1.1 กับดักของการไม่มีเฉลย
เมื่อไม่มีเฉลย เราจะไม่มีตัวชี้วัดความแม่นยำอย่าง Accuracy หรือ F1-Score 
* ถ้าอัลกอริทึมแบ่งลูกค้าออกเป็น 3 กลุ่ม (กลุ่ม A, B, C) เราจะรู้ได้อย่างไรว่ามัน "ถูกต้อง"?
* ความจริงคือ: **ใน Unsupervised Learning ไม่มีคำว่าถูกต้อง มีแค่คำว่า "มีประโยชน์" หรือไม่**

## 1.2 หลักฐาน 3 ชั้น (Triangulation of Evidence)
การประเมินผลงานแบบไม่มีเฉลย จะต้องใช้หลักฐาน 3 ชั้นประกอบกัน ก่อนนำไปให้ผู้บริหารตัดสินใจ:

1. **ความสมเหตุสมผลทางเทคนิค (Technical Validity):**
   - คณิตศาสตร์บอกว่าดีไหม? ลูกค้าในกลุ่มเดียวกันเกาะกลุ่มกันแน่นพอไหม? (Cohesion) และลูกค้าข้ามกลุ่มอยู่ห่างกันพอไหม? (Separation)
2. **ความหมายทางโดเมนธุรกิจ (Domain Meaning):**
   - เมื่อปริ้นท์รายชื่อลูกค้ากลุ่ม A ออกมาดู มนุษย์สามารถอธิบายได้ไหมว่าคนกลุ่มนี้คือใคร? (เช่น อ๋อ นี่คือกลุ่มวัยรุ่นชอบปาร์ตี้ดึก) 
   - ถ้ากลุ่มที่ AI จัดมาดูมั่วซั่ว อธิบายเป็นภาษามนุษย์ไม่ได้ แปลว่าโมเดลนั้นใช้ไม่ได้ทางธุรกิจ
3. **คุณค่าต่อการตัดสินใจ (Decision Value):**
   - สำคัญที่สุด! รู้แล้วเอาไปทำอะไรต่อได้ไหม? (Actionable) 
   - สมมติรู้ว่ามี "กลุ่มวัยรุ่นปาร์ตี้ดึก" แต่ธนาคารของเราไม่มีโปรดักต์หรือแคมเปญอะไรไปเสนอคนกลุ่มนี้เลย การค้นพบกลุ่มนี้ก็ถือว่าไร้ประโยชน์ทางธุรกิจ

## 1.3 กระบวนการที่ปลอดภัย (The Safe Process)
อย่าเริ่มที่การรันโค้ด K-Means แต่ให้เริ่มจาก:
`คำถามธุรกิจ` ➔ `กำหนดหน่วยวิเคราะห์` ➔ `ค้นหารูปแบบ (AI)` ➔ `ตรวจสอบความหมาย (มนุษย์)` ➔ `นำไปทดลองแคมเปญ (Experiment)` ➔ `เฝ้าระวังผล`

Unsupervised Learning เป็นเพียง **"เข็มทิศ"** ชี้เป้าให้มนุษย์ไปสำรวจต่อ ไม่ใช่ **"เครื่องจักรฟันธง"** เหมือน Classification
