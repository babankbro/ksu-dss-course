# 33. ทลายกล่องดำ: การจัดกลุ่มที่มนุษย์อธิบายได้ (Interpretable Clustering)

"CEO ไม่แคร์ว่าคุณใช้ DBSCAN หรือ K-Means เค้าแคร์แค่ว่า ทำไมลูกค้านาย ก. ถึงไปอยู่กลุ่ม 1?"
ในโลกของ Unsupervised Learning การให้กำเนิดคลัสเตอร์นั้นง่าย แต่การอธิบาย "กฎกติกาการเข้ากลุ่ม" ให้ฝั่งธุรกิจฟังนั้นยากยิ่งกว่างมเข็มในมหาสมุทร

## 33.1 กับดักของ Black Box Clustering
สมมติคุณโยนข้อมูล 50 คอลัมน์ เข้า K-Means แล้วได้ลูกค้ามา 5 กลุ่ม 
คุณพยายามอธิบายหัวหน้าว่า *"อ๋อ กลุ่มนี้คือคนที่มี Feature ที่ 17 สูงกว่าปกติ และ Feature ที่ 42 ต่ำกว่าปกติ บลาๆๆ"* 
หัวหน้าจะฟังไม่รู้เรื่อง และสั่งยกเลิกโปรเจกต์ทันที (เพราะเขาไม่กล้าเอาบริษัทไปเสี่ยงกับสิ่งที่เขาไม่เข้าใจ)

## 33.2 ทางแก้: เอา Decision Tree ไปครอบ K-Means (Surrogate Model)
นี่คือท่ามาตรฐานระดับปรมาจารย์ของ Data Scientist:
1. **สร้างเฉลย:** รัน K-Means ตามปกติ เพื่อจัดลูกค้า 1 ล้านคน ออกเป็นกลุ่ม (สมมติได้ผลลัพธ์ว่า นาย ก. อยู่กลุ่ม 1, นาย ข. อยู่กลุ่ม 2)
2. **เอา K-Means ไปเป็น Label:** เราจะหลอก AI ว่า ผลลัพธ์ (กลุ่ม 1,2,3) ที่ K-Means คิดให้ คือ "เฉลยที่ถูกต้อง" (Target Label)
3. **รัน Decision Tree ทับอีกรอบ:** นำข้อมูลดิบของลูกค้า 1 ล้านคน ไปรันโมเดล Decision Tree (ซึ่งเป็น Supervised Learning ยอดฮิตในสัปดาห์ 5) โดยตั้งเป้าให้ทำนาย "กลุ่มที่ K-Means จัดไว้ให้"
4. **ผลลัพธ์ที่จับต้องได้:**
   - คราวนี้ Decision Tree จะวาด "กิ่งไม้ (If-Then Rules)" ออกมาอย่างชัดเจน 
   - เช่น *"ถ้าลูกค้ามีอายุ > 35 ปี และ มียอดซื้อ > 5,000 บาท เขาจะถูกจัดไปอยู่กลุ่ม 1 (ความแม่นยำ 98%)"*
   - คุณสามารถปรินท์แผนผังต้นไม้นี้ ไปแปะบนโต๊ะหัวหน้าได้เลย!

## 33.3 อัลกอริทึม Interpretable โดยกำเนิด (เช่น IMM)
ปัจจุบัน นักวิจัยเริ่มสร้างอัลกอริทึมแนวใหม่ (Interpretable Mixture Models) ที่จะไม่ยอมสร้างกลุ่มมั่วซั่ว แต่มันจะบังคับตัวเองให้สร้างเฉพาะ "กลุ่มที่สามารถอธิบายด้วยกฎสั้นๆ (Short Rules)" ได้เท่านั้น 
แม้ความแม่นยำทางคณิตศาสตร์อาจจะสู้ K-Means ดั้งเดิมไม่ได้ แต่ "ความน่าเชื่อถือ (Trust)" ที่ฝั่งธุรกิจมีต่อโมเดลประเภทนี้จะพุ่งทะยานทะลุเพดาน!
