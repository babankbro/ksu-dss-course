## โครงสร้างรายวิชา

| ช่วง | สัปดาห์ | เนื้อหา |
|---|:--:|---|
| Part I | 1–2 | รากฐานการตัดสินใจ · กรอบ Simon · สถาปัตยกรรม DSS 4 ระบบย่อย |
| Part II | 3–7 | Data Warehouse · ETL · OLAP · Data Mining · Dashboard & Semantic Layer |
| — | 8 | สอบกลางภาค (25%) |
| Part III | 9–11 | Predictive ML · Optimization · Heuristics & Monte Carlo |
| Part IV | 12–14 | Fuzzy Logic · Bayesian Networks & ANFIS · Expert Systems & DMN |
| Part V | 15–16 | Decision Intelligence · Agentic AI · DecisionOps · นำเสนอโครงงาน |
| — | สอบ | สอบปลายภาค (30%) |

**การประเมิน:** สอบกลางภาค 25% · สอบปลายภาค 30% · งานเดี่ยว 15% · งานกลุ่ม 25% · ปฏิบัติการ 5%

## สื่อจำลองเชิงโต้ตอบ

```bash
npm --prefix web install && npm --prefix web run dev
```

เปิด http://localhost:3000

| สื่อจำลอง | สัปดาห์ | สอนอะไร |
|---|:--:|---|
| 🎛️ Decision Cockpit | W1–W2 | เดินผ่านกระบวนการตัดสินใจของ Simon ครบ 4 ระยะ แล้วเทียบผลระหว่างไม่มีระบบ / มี BI / มี DSS บนเหตุการณ์ชุดเดียวกัน |
| 🧊 OLAP Cube Explorer | W3–W4 | ลูกบาศก์ข้อมูลที่หมุนได้ กด Roll-up / Drill-down / Slice / Dice / Pivot แล้วเห็น SQL ที่เทียบเท่าถูกสร้างพร้อมกัน |

สื่อจำลองทุกตัวใช้ตัวสุ่มแบบกำหนดเมล็ด ผลลัพธ์จึงเหมือนกันทุกเครื่องทุกครั้ง — เฉลยหน้าชั้นเรียนได้
ประมวลผลในเบราว์เซอร์ทั้งหมด ไม่มี backend และไม่ส่งข้อมูลออกนอกเครื่อง
หากเปิดเซิร์ฟเวอร์ไม่ได้ ใช้ไฟล์ HTML เดี่ยวใน [06-Simulations/](06-Simulations) แทนได้ทันที
